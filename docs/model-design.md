# 模型设计说明

面向 PatchCore 的模型结构、输出语义与阈值口径。不含任何宿主程序实现细节。

---

## 1. v2 架构：ROI 由外部裁剪

早期版本把 ROI 作为常量 Slice 固化在 ONNX 图里，ROI 一变就得重新导模型。
v2 把 ROI 裁剪交给调用方：**整数裁剪、无缩放、无重采样**，不引入任何预处理偏差。

```
外部 : 原图 → 按 ROI 整数裁剪 → uint8 单通道 (1,1,h,w)
ONNX : Cast 复制为 3 通道
       → Resize 256×256 (antialias=1)
       → 中心裁剪 224×224
       → /255 + ImageNet 归一化
       → 骨干 (wide_resnet50, layer2+layer3) → embedding (784, 1024)
       → 与内嵌记忆库算 KNN → 每个 patch 的平方 L2 距离
       → ReduceMax = 图像分数
       → 28→224 上采样 + 高斯平滑 = 热图
输出 : score float[1,1]
       anomaly_map float[1,1,224,224]
```

### 关键约束

**Resize 目标尺寸必须是常量 256×256。**
ONNX Runtime 1.17 不支持由算子动态计算出的 `sizes`，会报：

```
Number of elements of input 'sizes' (0) must be same as rank of input 'X' (4)
```

**必须"先 256 再裁 224"，不能直接缩到 224。**
直接缩到 224 会掉一档分辨率，实测 cam1 的弱缺陷分数从 0.618 掉到 0.528，
检出从 10/10 变 9/10。

**外部裁剪必须与建库时一致。**
建库用的是抗锯齿缩放到 256，若调用方自己先做了非抗锯齿 LINEAR 重采样，
特征就对不上——实测正常料的分数会翻倍并被判成 NG。

## 2. 输出语义

| 输出 | 含义 | 方向 |
|---|---|---|
| `score` | 图像级异常分 | **越大越差**（与 YOLO 的 score 相反） |
| `anomaly_map` | 224×224 热图，逐 patch 异常程度 | 越大越异常 |

热图坐标 → 原图坐标需要计入缩放与中心裁剪偏移（`16 = (256-224)/2`）：

```
sx = roi_w / 256          sy = roi_h / 256
x  = roi_x + (map_x + 16) * sx
y  = roi_y + (map_y + 16) * sy
```

缺陷区域 = 热图上超过 `阈值 × 系数` 的 8 连通域，再按面积/数量筛选。

## 3. 实测指标（v2，全量标定）

| 相机 | 样本 | 均值 | std | p99 | 正常最大 | 阈值 | 最弱可检出 NG | 检出 | 耗时(CPU) |
|---|---|---|---|---|---|---|---|---|---|
| cam1 | 372 | 0.4910 | 0.0167 | 0.5351 | 0.5675 | **0.59** | 0.636 | **10/10** | 204 ms |
| cam2 | 371 | 0.4604 | 0.0160 | 0.5036 | 0.5450 | **0.56** | 0.631 | **4/4** | 198 ms |

- 分离窗口：cam1 `0.5675 → 0.636`（0.069）；cam2 `0.5450 → 0.631`（0.086）
- 阈值取 `mean + 6σ`，并与正常最大值取较大者
- 跨实现一致性：Python 与 ONNX Runtime 推理分数差 **0.0000**（16/16 通过）

## 4. 置信度映射（供上位机使用）

上位机常需要"越大越好"的分数，需把异常分翻转。两种公式：

### 公式 A：按阈值归零（简单）

```
conf = clamp(1 - score / 阈值, 0, 1) × 1000
```

| 情形 | cam1 | cam2 | conf |
|---|---|---|---|
| 正常均值 | 0.491 | 0.460 | 168 / 178 |
| 正常最大 | 0.568 | 0.545 | 38 / 27 |
| 阈值处 | 0.59 | 0.56 | 0 |
| 任意 NG | ≥0.636 | ≥0.631 | 0 |

⚠️ 这个公式下**正常料只有 168~178 分**（不是接近 1000），且**所有 NG 都是 0**。
如果操作员把 1000 理解为"完美"，观感会很差。

### 公式 B：按正常均值归零（推荐）

```
conf = clamp((阈值 - score) / (阈值 - 正常均值), 0, 1) × 1000
→ 正常均值 ≈ 1000，阈值处 = 0
```

`正常均值` 已记录在 `meta_v2.json` 的 `normal_mean` 字段，直接取用。

两种公式都保留切换能力，默认按实际部署方要求选一种并保持一致。

## 5. 部署目录建议

按相机分目录，每个相机一套模型与元数据：

```
<程序目录>/PatchCore/
├─ cam1/  patchcore_roi.onnx   meta_v2.json
└─ cam2/  patchcore_roi.onnx   meta_v2.json
```

模型约 190MB（wide_resnet50 + 内嵌记忆库），加载需 2~4 秒。
建议**懒加载 + 常驻**，不要每帧重建会话。
